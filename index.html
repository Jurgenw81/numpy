1. Why NumPy exists

Ordinary Python is convenient, but its flexible object model makes low-level optimization difficult. NumPy provides optimized numerical operations—typically implemented in compiled C while remaining accessible from Python.

Python objects

Python lists can hold references to objects of different types. That flexibility is useful, but numerical operations have more runtime work to do.

NumPy arrays

An array normally stores values using one fixed data type, so operations can be implemented much more efficiently.

The payoff

You write Python-level code while optimized functions handle much of the numerical work underneath.

2. The ndarray

NumPy mainly works with multidimensional array data through numpy.ndarray. Every element in an array has the same data type.

Explore dtype

a = np.array([1, 2, 3, 4], dtype=np.int16)
4 values × 2 bytes = 8 bytes of element storage

Why one dtype matters

The array carries the information needed to interpret its stored bit patterns. Because elements use the same encoding, NumPy doesn't need to rediscover the type of every element during each numerical operation.

Changing dtype generally means creating or viewing array data under a different representation; the lecture emphasizes that a given array's element type is fixed.

4. Multidimensional arrays are flat underneath

NumPy can represent n-dimensional data using a flat memory layout. In the lecture, row-major order is the default: consecutive elements of a row sit next to each other.

3 × 5 array

How the flat index is found

For a row-major 2D array with 5 elements per row:

flat_index = 5 * row + column

For row 2, column 3:

5 * 2 + 3 = 13

NumPy performs this address calculation for you when you write multidimensional indexing syntax.
